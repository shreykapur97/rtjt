# cowork/

Design space for the review workflow: drafts, research and rules worked out between Claude Code
and Shrey before anything goes live in `reviews/WORKFLOW.md`.

- **Tracked in git.** The repo is public: no student names in these files.
- **Not live.** Nothing here is instructions for Claude Code or Cowork. Rules are copied into
  `reviews/WORKFLOW.md` only once they are agreed.
- Cowork works in `reviews/` and never gets access to `dev/`, including this folder.

## Files
| File | What it is |
|---|---|
| `case-study.md` | Research: established ways to record, transcribe and structure thesis review notes, and what they mean for RTJT |
| `evaluation.md` | Draft criteria for evaluating each thesis (guiding, not grading) |
